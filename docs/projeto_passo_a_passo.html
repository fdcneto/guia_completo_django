Guia Mão na Massa: Django do Zero ao Deploy

Este documento consolida o passo a passo prático para criar, configurar e publicar um projeto Django profissional, utilizando o exemplo do projeto "Sebastião Tavares".

1. Fundamentos: O Ambiente Virtual

Antes de escrever código, precisamos preparar o terreno. A regra de ouro no Django é: Nunca instale bibliotecas no Python global do seu computador.

1.1 Por que usar .venv?

Imagine o .venv (Virtual Environment) como uma "caixa vazia".

  • Global: Se você instalar o Django no PC, versões diferentes de projetos antigos e novos entrarão em conflito.
  • Virtual (.venv): Cada projeto tem sua própria caixa com suas próprias ferramentas.
Limpeza (Opcional): Se você já instalou Django globalmente, remova-o: 
deactivate
pip uninstall django

2. O Ritual de Início (Setup)

Siga este ritual sempre que começar um projeto novo no terminal.

2.1 Criando a Estrutura e o Ambiente

# 1. Criar a pasta do projeto
mkdir meu_primeiro_django
cd meu_primeiro_django

# 2. Criar a "Caixa" (.venv)
python -m venv .venv

# 3. Ativar o Ambiente (CRUCIAL!)
# No Windows:
.\.venv\Scripts\activate
# No Mac/Linux:
source .venv/bin/activate

# 4. Instalar o Django
pip install django

2.2 Iniciando o Projeto

Com o Django instalado, criamos os arquivos base. O ponto final . é importante para não criar subpastas desnecessárias.

django-admin startproject core .

2.3 Teste de Fogo

python manage.py runserver

Acesse http://127.0.0.1:8000/. Se ver o foguetinho, funcionou! 🚀

3. Configurações Iniciais

Abra o arquivo core/settings.py para "tropicalizar" o projeto.

LANGUAGE_CODE = 'pt-br'
TIME_ZONE = 'America/Sao_Paulo'
USE_TZ = True

Congelando Requisitos

Para salvar a lista de bibliotecas instaladas (útil para o deploy):

pip freeze > requirements.txt

4. Banco de Dados e Admin

O Django precisa criar as tabelas iniciais para o sistema de login funcionar.

4.1 Migrations e Superusuário

# Cria as tabelas iniciais (db.sqlite3)
python manage.py migrate

# Cria o admin (Siga os passos de senha)
python manage.py createsuperuser

Acesse /admin para testar o login.

5. Criando o Primeiro App (website)

O projeto (core) é o prédio. O App é o apartamento.

5.1 Criar e Registrar

python manage.py startapp website

Vá em core/settings.py e adicione em INSTALLED_APPS:

INSTALLED_APPS = [
    # ... apps do django ...
    'website',
]

5.2 O Ciclo MVT (Model-View-Template)

1. View (website/views.py):

from django.shortcuts import render

def index(request):
    return render(request, 'website/index.html')

2. URL (core/urls.py):

from django.urls import path
from website.views import index

urlpatterns = [
    path('admin/', admin.site.urls),
    path('', index, name='index'),
]

3. Template (HTML): Crie website/templates/website/index.html.

6. Contexto e Arquivos Estáticos

6.1 Passando Dados (Contexto)

Na View, enviamos um dicionário para o HTML:

def index(request):
    dados = {'nome_empresa': 'Sebastião Tavares'}
    return render(request, 'website/index.html', dados)

No HTML, usamos {{ nome_empresa }}.

6.2 CSS e Imagens

Estrutura de pastas: website/static/website/style.css

No HTML:

7. Modelos: O Banco de Dados Real

Substituindo dados falsos por tabelas reais.

7.1 Criando o Modelo (models.py)

class Servico(models.Model):
    titulo = models.CharField(max_length=100)
    descricao = models.TextField()

    def __str__(self):
        return self.titulo

7.2 Aplicando no Banco

python manage.py makemigrations
python manage.py migrate

7.3 Registrar no Admin (admin.py)

from .models import Servico
admin.site.register(Servico)

9. Funcionalidades Avançadas

9.1 URLs Dinâmicas (Detalhes)

Para acessar /servico/1/.

  • URL: path('servico/<int:id>/', detalhe_servico)
  • View: item = get_object_or_404(Servico, id=id)
  • HTML: {% url 'detalhe_servico' item.id %}

9.2 Formulários (Contato)

  1. Criar modelo Contato.
  2. Criar forms.py com ModelForm.
  3. Na View, validar com form.is_valid() e salvar com form.save().
  4. No HTML, usar a tag de segurança {% csrf_token %}.

10. Deploy: Publicando na Nuvem

Usando o PythonAnywhere e GitHub.

10.1 Preparação (Local)

  1. settings.py: ALLOWED_HOSTS = ['*']
  2. settings.py: STATIC_ROOT = os.path.join(BASE_DIR, 'static_root')
  3. Gerar requirements: pip freeze > requirements.txt
  4. Subir tudo para o GitHub (`git push`).

10.2 Configuração (Nuvem)

  1. Clonar o repositório no Console Bash.
  2. Criar venv, instalar requirements, rodar migrate.
  3. Rodar python manage.py collectstatic (para o CSS).
  4. Configurar Web App (Manual Config).
  5. Apontar arquivo WSGI e Pasta Static (`/static/` -> `static_root`).

Sucesso! Ao clicar em Reload, seu site estará online.
